{% comment %} Icono de cada envío automático de plantilla (`WhatsAppTemplate.Purpose`): campana para el recordatorio, check para la cita confirmada, flechas circulares para el cambio y aspa para la cancelada. Parámetros: `purpose` (el valor) y `classes` (tamaño, por defecto h-4 w-4). Hereda el color del texto (`currentColor`), así que quien lo incluye elige el token. {% endcomment %}
